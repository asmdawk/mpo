# ZigZak Player 1.0

Музыка и видео в одном красивом приложении. Работает локально, без регистрации и подключения к интернету.

## Запуск

Для Windows 10/11, 64 бит (x64). Запустите **ZigZak-Player-1.0.0-Windows-x64.exe**. Установка и права администратора не нужны. При первом запуске приложение распаковывает встроенные компоненты во временную папку — это может занять несколько секунд.

Нажмите **«Добавить файлы»**, откройте папку или перетащите музыку и видео в окно. Кнопка **«Поймать настроение»** включает встроенную оригинальную композицию Neon Skyline.

## Возможности

- MP3 и MP4 (включая H.264/AAC), а также WAV, FLAC, OGG, M4A и WebM. Для остальных контейнеров воспроизведение зависит от кодеков файла.
- Обложки и названия из метаданных, поиск по коллекции, избранное и история прослушивания.
- Пауза, перемотка, случайный порядок, повтор очереди или одного трека.
- Полноэкранное видео.
- Три темы оформления: Aurora, Violet и Sunset; переключаются цветными кнопками в верхней панели.
- Эквалайзер на 10 полос с пресетами, скорость 0,5–2× и таймер сна.
- Импорт M3U/M3U8 и JSON, экспорт M3U8 в UTF-8.
- Автоматическое сохранение библиотеки, избранного, настроек и позиции. Медиафайлы остаются в исходных папках.

## Клавиши

| Клавиша | Действие |
|---|---|
| Пробел | Воспроизведение / пауза |
| ← / → | Перемотка на 5 секунд |
| ↑ / ↓ | Громкость |
| M | Выключить / включить звук |
| F | Полный экран |
| Esc | Закрыть диалог / выйти из полного экрана |
| Ctrl+O | Добавить файлы |
| Ctrl+F | Поиск |

Библиотека и настройки хранятся в `%APPDATA%\ZigZak Player\library.json`. «Очистить медиатеку» убирает записи из приложения; исходные файлы сохраняются.

## О сборке

Это неподписанная переносимая сборка: Windows может показать уведомление о неизвестном издателе. Приложение собрано под Windows x64; работа на физическом компьютере с Windows в этой среде не проверялась.

Проверены воспроизведение реальных MP3 и MP4, декодирование кадров видео, потоки с поддержкой перемотки, управление звуком, полноэкранный режим, эквалайзер, импорт и экспорт, сохранение и восстановление состояния. Проверки выполнялись в Chromium и Electron на Linux, включая упакованный код приложения.

Демо-композиция и оформление созданы для ZigZak Player. Приложение использует Electron, music-metadata и шрифт Manrope; сведения о сторонних лицензиях входят в пакет приложения.
